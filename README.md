# Drivstoffkalkulator

Enkel kalkulator som sammenligner bensin/diesel med elbil.

Legg inn år, forbruk, årlig kjørelengde og priser, og trykk **Beregn**. Du får estimert besparelse, kostnad per mil, akkumulert kostnad og et omtrentlig CO₂-tall med norsk strømmiks.

Tallene kan være feil. Beregningen er kun til illustrasjon og er ikke økonomisk eller miljømessig rådgivning.

## Kjøre lokalt

```bash
npm install
npm run dev
```
